apiome
Hive design language · mockups

A calmer, warmer Apiome people want to open.

One collapsible rail instead of two bars, warm paper surfaces with navy ink and one azure accent, jobs-to-be-done navigation, ⌘K everywhere, drawers instead of page hops, humane empty states — and a Preferences pane for theme, font size and density. Every screen below re-implements the functionality of its current route.
