Rail anatomy
264 px · 64 px collapsed
  1. 1
    Brand — hex mark + “apiome / Platform”. Click → All apps launcher (/ade). Admin shell shows “Admin console” in rose.
  2. 2
    Workspace switcher — hex avatar, tenant name, role · plan. Opens the tenant menu (search, role badges, license chips, suspended rows, “Create workspace” with cap “n/m used”). Replaces the header tenant pill.
  3. 3
    Search / ⌘K — opens the command palette: jump, actions, recent, > commands.
  4. 4
    Nav groups — Home · Build · Bring in · Ship · Govern · Workspace · Tools (DESIGN.md §6). Labels collapse per group (persisted). Items: 32 px, hover tint, active = raised white pill with azure icon. Tenant-gated items render at 45 % with a tooltip. Commercial suite items are injected by the host.
  5. 5
    Footer — Help & docs · Preferences (⌘,) · user button → Profile, Linked accounts, Preferences, What’s new (honey dot), Shortcuts, Admin console, All apps, Sign out, build string.
  6. 6
    Collapse handle — appears on hover at the rail edge; icon rail keeps hex avatar, search icon, group hairlines and hover tooltips.

Admin shell
Open

Same rail, rose-tinted (.rail--admin) with “Admin console” under the brand, its own groups (Overview · Directory · Commercial · Platform) and a “Back to app” item. No workspace switcher, no ⌘K search (admin has no tenant scope). Dead links (Payments, Database, Monitoring) are removed.

Responsive

≥ 1280: expanded rail. 900–1280: rail expanded, 4-col grids fold to 2. < 900: rail forced to icon mode, page padding 24, tables scroll inside their card, page actions wrap under the title. Auth/launcher pages are single column below 960.
